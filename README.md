# ocean_climate-Project
Final project for ATOC 4815. A package designed to implement comparison of how long term climate patterns affect ocean profiles. Assuming working with netCDF files. Connects to public Arco ERA5 Datasets.

Run with:   python ocean_climate_ensemble.py --component ocn --scenario historical --forcing cmip6 --time-slice 1990-01 2000-12 --lat-box 5 -5 --lon-box -155 -120
